devbox repo (~/.local/share/devbox-home) formatting architecture: single source of truth = .config/language/languages.lua — M.formatters (cmd/args/config/write/exts) + M.languages (filetypes/treesitter/linter/formatter/lsp, lsp={name,config}). Consumed by nvim init.lua (dofile + conform prepend_args) and scripts/format.lua (luajit; `format <dir>`|`--staged`; md5 before/after to report changed vs scanned; redirects formatter output to temp log shown only on failure; excludes .config/language/ so biome never formats its own biome.json). Configs in .config/language/; .editorconfig stays at root. fish fn `format` → $HOME/scripts/format.lua. Hook githooks/pre-commit, wired via core.hooksPath githooks in just setup. 2-space, 120 col. <!-- created=2026-08-30, last=2026-08-30 -->
