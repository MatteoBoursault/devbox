Architecture de formatage devbox : source de vérité unique = .config/language/languages.lua (Lua pur, chargé par luajit standalone ET nvim via dofile) — M.formatters (cmd/args/config/write/exts) + M.languages (filetypes/treesitter/linter/formatter/lsp, lsp={name,config}). Configs formatters dans .config/language/ (chemins absolus auto-résolus depuis l'emplacement du fichier) ; .editorconfig à la racine (spec EditorConfig).
