# Raccourcis — Dvorak for programmer

**herdr**
  `ctrl+shift+r`                      panneau resize
  `ctrl+h/t/n/s`                      panneau focus
  `ctrl+shift+h/t/n/s`                panneau swap
  `ctrl+shift+v/b`                    panneau split vertical / horizontal
  `ctrl+shift+q`                      panneau close
  `ctrl+a/u` · `ctrl+o` · `ctrl+e`    onglet prev / next · new · close
  `ctrl+shift+a/u`                    workspace prev / next
  `ctrl+shift+o` · `ctrl+shift+e`     workspace new · close
  `ctrl+k`                            show keybinding

**kitty**
  `ctrl+y/p`                          copy / past
  `ctrl+x`                            scrollback dans nvim
  `alt+l/p`                           prompt next / prev
  `alt+u/c/h`                         hints url / path / hash

**yazi**
  `h` · `t/n` · `s`                   parent · ligne next / prev · entrer
  `T/N`                               parent next / prev
  `m` · `'` · `bd/bD`                 bookmark save · jump · delete
  `x`                                 shell

**nvim** (leader = espace)
  `t/n` · `h/s`                       bas / haut · droite / gauche
  `l/L`                               resultat recherche next / prev
  `<l>sv/sb`                          split vertical / horizontal
  `<l>bl/bp`                          buffer next / prev
  `<l>ff fg fb f. fh fr`              pickers files / grep / buffers / recents / help / resume
  `K grd grr gri grt grn gra`         LSP hover / def / ref / impl / type / rename / action
  `gO gW` · `<l>th`                   symboles doc / ws · inlay hints
  `<l>f` · `<l>d/td` · `<l>sw`        format · diagnostics · grep word
  `<l>w` · `<l>q`                     save / quit
  `<Esc>`                             fin surlignage recherche
